# DIT Degree Planner

Ένα διαδραστικό εργαλείο σχεδιασμού σπουδών για το Τμήμα Πληροφορικής και Τηλεπικοινωνιών του ΕΚΠΑ.

## Δυνατότητες

- Οργάνωση μαθημάτων σε 8 εξάμηνα
- Μετακίνηση μαθημάτων με drag-and-drop
- Παρακολούθηση προόδου προς τις 240 μονάδες ECTS
- Αναζήτηση με τίτλο ή κωδικό μαθήματος
- Φίλτρα ανά εξάμηνο και τύπο μαθήματος
- Εμφάνιση σε λίστα ή πλέγμα
- Αυτόματη αποθήκευση του πλάνου στον browser
- Responsive σχεδίαση για υπολογιστή, tablet και κινητό

## Εγκατάσταση

Απαιτείται το [Node.js](https://nodejs.org/) έκδοσης 18 ή νεότερης.

```bash
npm install
```

## Εκτέλεση

Για τοπική ανάπτυξη:

```bash
npm run dev
```

Στη συνέχεια άνοιξε τη διεύθυνση που εμφανίζεται στο terminal, συνήθως `http://localhost:5173`.

## Production build

```bash
npm run build
```

Τα αρχεία παραγωγής δημιουργούνται στον φάκελο `dist`.

Για προεπισκόπηση του production build:

```bash
npm run preview
```

## Έλεγχος κώδικα

```bash
npm run lint
```

## Τεχνολογίες

- React
- Vite
- Lucide React
- CSS

## Αποθήκευση δεδομένων

Το πλάνο αποθηκεύεται τοπικά μέσω `localStorage`. Δεν αποστέλλονται δεδομένα σε server και κάθε browser ή συσκευή διατηρεί ξεχωριστό πλάνο.

> Το DIT Degree Planner είναι προσωπικό βοήθημα οργάνωσης και δεν αντικαθιστά τον επίσημο οδηγό σπουδών του Τμήματος.
